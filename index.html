Department of Dravyaguna
Vrikshamala
Botanical Name :

  • Garcinia cambogia

    • Family Name :

  • Clusiaceae

    • Local Name :

  • Vrikshamla / Kodampuli / Malabar tamarind

    • Vernacular Name :

  • Hindi – Vrikshamla

  • English – Malabar Tamarind

    • Habitat :

  • Grows in tropical evergreen forests of South India

  • Especially Western Ghats; also cultivated in humid tropical regions


    • Morphology :

  • Small to medium-sized evergreen tree

  • Leaves: Simple, glossy, dark green

  • Flowers: Small, yellowish, solitary or clustered

  • Fruit: Pumpkin-shaped, green turning yellow when ripe

  • Bark: Dark brown


    • Useful Parts :

  • Fruit rind

  • Leaves


    • Chemical Constituents :

  • Hydroxycitric acid (HCA)

  • Citric acid

  • Flavonoids

  • Tannins


    • Actions :

  • Digestive stimulant

  • Appetite suppressant

  • Carminative

  • Antioxidant


    • Properties :

  • Supports digestion

  • Helps regulate appetite

  • Antioxidant activity

  • Mild anti-inflammatory


    • Indications :

  • Indigestion

  • Obesity

  • Loss of appetite imbalance


    • Dose :

  • Powder: 1–3 g

  • Decoction: 20–50 ml


    • Formulations :

  • Vrikshamala Churna
